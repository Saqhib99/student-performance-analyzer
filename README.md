# Student Performance Analytics System — V2

A Python-based student performance analysis and visualization project.

## Project Details

**Project Title:** Student Performance Analytics System

**Program Name:** Student Performance Analyzer

**Developed by:** Md Saqhibuddin Ahmed

## Features

- View student records
- Analyze student performance
- Generate individual student reports
- Class performance summary
- Subject-wise performance analysis
- Top performers analysis
- Student name search
- Department filtering
- Percentage filtering
- Grade filtering
- Pass/fail filtering

## Technologies Used

- Python
- Pandas
- NumPy
